# Fonts

Instrument Sans and IBM Plex Mono, both under the SIL Open Font License.
They are here so the charts are set in the same faces as the case study
that shows them, and so the notebook renders identically on a machine that
has neither installed.

- Instrument Sans: https://fonts.google.com/specimen/Instrument+Sans
- IBM Plex Mono: https://fonts.google.com/specimen/IBM+Plex+Mono
